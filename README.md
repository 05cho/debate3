# 우리들의 생각 공장 - 실시간 통합 무기명 학급 토론 웹앱 💡

> 초·중·고등학교 수업 현장에서 학생들이 심리적 부담 없이 자유롭게 생각을 표현하고, 교사가 3가지 토론 모드를 손쉽게 통제할 수 있는 **React & Tailwind CSS & Supabase (또는 Firebase)** 기반의 실시간 무기명 토론 웹 애플리케이션입니다.

---

## 📖 1. 앱 개요 및 주요 기능

### 🎯 기획 의도
- 발표에 소극적이거나 친구들의 시선이 부담스러운 학생들도 적극적으로 수업에 참여할 수 있도록 **완전 무기명(동물/지혜 닉네임 자동 부여)** 환경을 제공합니다.
- 교사는 수업 목표에 맞춰 **찬반 토론, 자유 의견 모으기(포스트잇), 3단계 구조화 토론(입론 ➔ 반론 ➔ 최종발언)** 중 원하는 모드를 실시간으로 전환할 수 있습니다.
- 학생 간에는 철저히 익명이 보장되지만, 교사 전용 관리자 모드에서는 **실명 확인(학년/반/번호/이름)** 및 **부적절한 의견 삭제/블라인드**를 통해 건전하고 안전한 수업 문화를 유지합니다.

### 🌟 핵심 기능 요약

1. **학생 무기명 인증 & 캐릭터 생성**
   - 학년, 반, 번호, 이름, 4자리 비밀번호(PIN)로 간편 접속
   - 접속 시 시스템이 '지혜로운 사자 🦁', '당당한 독수리 🦅', '따뜻한 돌고래 🐬' 등 100+ 가지의 긍정적인 무기명 닉네임과 동물 이모티콘을 자동 생성 및 부여
   - 친구들에게는 무기명 닉네임만 표시되어 편견 없는 토론 보장

2. **3가지 맞춤형 토론 모드**
   - **모드 1: 찬반 토론**
     - 찬성 / 중립 / 반대 실시간 투표 게이지 바 (비율 % 및 인원수 실시간 렌더링)
     - 입장별 파스텔 카드 피드 및 필터링 기능
     - 공감(좋아요) 및 스레드 댓글 소통
   - **모드 2: 자유 의견 모으기**
     - 6가지 파스텔 컬러(레몬, 핑크, 민트, 라벤더, 블루, 피치)의 포스트잇 보드
     - 실시간 하트 공감 및 한 줄 댓글 토론
     - 최신순 / 공감 많은 순 실시간 정렬
   - **모드 3: 3단계 구조화 토론**
     - 1단계(입론: 주장과 근거) ➔ 2단계(반론: 반박과 질문) ➔ 3단계(최종발언: 정리 및 결론) 진행 바
     - 교사가 단계를 넘기면 학생들의 입력 폼과 탭이 실시간으로 즉시 전환
     - 이전 단계의 발언을 원클릭으로 인용하여 반론을 펼칠 수 있는 구조화 UX

3. **교사 전용 스마트 관리자 기능 (Teacher Admin)**
   - 관리자 PIN으로 교사 모드 전환
   - 토론 안건/논제 출제 및 수정
   - 3가지 토론 모드 및 3단계 순차 제어
   - **실명 확인 모드**: 각 의견별 또는 전체 게시글의 실제 작성 학생 정보(학년/반/번호/이름) 원클릭 조회
   - 부적절한 글 블라인드 및 즉시 삭제
   - 신규 의견 제출 일시정지 / 활성화 제어
   - **토론 결과 엑셀(CSV) 다운로드**: 학생 실명, 닉네임, 찬반 입장, 내용, 공감수 등 수업 기록 보관용 내보내기
   - 요약 텍스트 리포트 클립보드 복사

4. **모던한 감성 디자인 & 반응형 지원**
   - **칠판 다크 모드 (Chalkboard Dark)**: 실제 교실 칠판 느낌의 아늑한 초록 톤 테마
   - **화사한 파스텔 모드 (Pastel Classroom)**: 부드럽고 가독성 높은 밝은 테마
   - 스마트폰, 태블릿, PC 및 교실 대형 전자칠판/빔프로젝터에 최적화된 반응형 UI

## ⚡ 2. Supabase 설정 가이드 (권장 백엔드)

프로젝트 개수 제한 스트레스 없이 단 2개의 키(`URL`, `Anon Key`)로 간편하게 실시간 토론 서버를 연동할 수 있습니다.

### 1단계: Supabase 프로젝트 생성
1. [Supabase 콘솔](https://supabase.com/)에 접속하여 가입 또는 로그인합니다.
2. **[New project]**를 클릭하고 프로젝트 이름(예: `school-debate`)과 데이터베이스 암호를 입력한 후 생성합니다.

### 2단계: 테이블 및 실시간 복제 생성 (1-Click SQL)
1. 좌측 메뉴에서 **SQL Editor**를 클릭합니다.
2. **[New query]**를 누르고 프로젝트의 `supabase-schema.sql` 내용을 붙여넣은 뒤 우측 하단 **[Run]**을 클릭합니다.
   - `discussions`, `posts`, `comments` 테이블 3개 자동 생성
   - Row Level Security (RLS) 및 실시간 Realtime 동기화 활성화

### 3단계: API 키 확인
- 좌측 하단 **Project Settings (톱니바퀴 ⚙️)** ➔ **API** 메뉴에서 아래 2개 값을 복사합니다:
  - **Project URL**: `https://xxxxxxxxxxxx.supabase.co`
  - **Project API Keys (anon / public)**: `eyJhbGciOi...`

## 🚀 3. GitHub 업로드 및 Vercel 배포 방법

### 1단계: GitHub 저장소 생성 및 푸시
```bash
git init
git add .
git commit -m "feat: 우리들의 생각 공장 실시간 무기명 토론 웹앱"
git branch -M main
git remote add origin https://github.com/<your-username>/school-debate.git
git push -u origin main
```

### 2단계: Vercel 배포
1. [Vercel](https://vercel.com/)에 로그인하고 **[Add New...]** ➔ **[Project]**를 선택합니다.
2. 방금 올린 GitHub 저장소를 찾아 **[Import]**를 클릭합니다.
3. **Environment Variables (환경 변수)** 섹션에 아래 2개를 등록합니다:
   - `VITE_SUPABASE_URL`: (Supabase Project URL)
   - `VITE_SUPABASE_ANON_KEY`: (Supabase anon public key)
4. **[Deploy]** 버튼을 누르면 1분 만에 고유 웹 주소(`https://school-debate.vercel.app`)로 배포 완료됩니다!

## 🔒 4. 보안 및 학급 운영 수칙
- 학생 정보는 외부 유출 없이 교사의 관리자 화면에서만 복호화되어 표시됩니다.
- 타인의 글은 학생 본인이 임의로 수정/삭제할 수 없으며, 교사의 권한으로만 삭제 및 블라인드가 가능합니다.
- 토론 종료 후 교사는 즉시 엑셀(CSV)로 학생 발언 통계를 다운로드하여 생기부/수업 관찰 기록에 활용할 수 있습니다.
